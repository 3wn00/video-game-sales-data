# Video Game Sales Geolocation Heatmap

## Overview
This small project visualizes global video game sales using the Kaggle "Video Game Sales" dataset. It shows how video game popularity varies across different regions using an interactive heatmap.

Dataset: https://www.kaggle.com/datasets/gregorut/videogamesales

---

## Goal
- Analyze global video game sales
- Compare regional markets (NA, EU, JP, Other)
- Visualize sales distribution using a world heatmap

---

## Tech Stack
- Python
- Pandas
- Plotly
- Jupyter Notebook

---

## Features
- Loads and cleans dataset
- Aggregates sales by region
- Creates interactive heatmap
- Optional filtering by genre, platform, and year

---

## Key Insight
North America and Europe dominate global video game sales, while Japan and other regions contribute smaller shares.

---

1. Clone repository

3. Open Jupyter Notebook  
4. Run all cells
